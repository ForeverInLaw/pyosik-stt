# Pyosik для Android

Плагин для AyuGram / exteraGram с Python SDK 1.4.5.0 или новее.
Автоматически расшифровывает новые исходящие голосовые через NVIDIA Riva
Whisper Large v3 и добавляет текст к голосовому сообщению.

Исходная Windows-версия использует `riva_helper.exe`. Android-версия
обращается к тому же gRPC API напрямую через `grpclib` и `protobuf`.
API-ключ вводится в настройках плагина и не включается в исходники.

Инструкции по установке и проверке будут добавлены вместе с плагином.
