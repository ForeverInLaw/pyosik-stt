# Pyosik для Android

Плагин для AyuGram / exteraGram с Python SDK 1.4.5.0 или новее.
Автоматически расшифровывает новые исходящие голосовые через NVIDIA Riva
Whisper Large v3 и добавляет текст к голосовому сообщению.

Исходная Windows-версия использует `riva_helper.exe`. Android-версия
обращается к тому же gRPC API напрямую через `grpclib` и `protobuf`.
API-ключ вводится в настройках плагина и не включается в исходники.

## Установка

Для уже подключённого через ADB телефона с активным Dev Server:

```powershell
C:\adb\adb.exe forward tcp:42690 tcp:42690
python tools/dev.py install
```

Команда загружает `pyosik.py`, включает плагин и проверяет его состояние.
Во время первого включения SDK установит зависимости с PyPI.
Других файлов для работы на телефоне не требуется.

В настройках Pyosik введи NVIDIA API-ключ с доступом к Whisper Large v3.
Язык `multi` включает автоматическое определение. Для известного языка можно
указать `ru`, `en` или другой код из документации модели.

Отправь короткое голосовое в «Избранное». После распознавания текст появится
под голосовым как подпись в виде цитаты, видимая всем участникам чата.

## Поведение и ограничения

- Обрабатываются только новые исходящие голосовые после включения плагина.
  Пересланные сообщения, готовые подписи, секретные чаты, сообщения с TTL
  и отложенные сообщения пропускаются.
- Загрузка аудио в NVIDIA начинается после подтверждения отправки Telegram.
  Используется локальный OGG-файл, повторное скачивание из Telegram не нужно.
  Распознавание требует интернета и действующего ключа NVIDIA.
- Очередь ограничена четырьмя голосовыми, одновременно распознаётся одно.
  Размер аудиофайла ограничен 20 МиБ, таймаут запроса составляет 60 секунд.
  Ошибки показываются уведомлением внутри приложения.
- Лимит подписи берётся из Telegram для конкретного аккаунта. Длинный текст
  не обрезается: его можно скопировать через «Скопировать последнюю
  расшифровку» в настройках. Это также работает при ошибке редактирования.
  Последний текст хранится только в памяти до отключения или перезагрузки.
- Каждый запрос использует аккаунт исходного сообщения. При отключении
  плагина подписки снимаются, незавершённое распознавание отменяется.
  После отправки запроса редактирования Telegram уже может применить его.

## Разработка

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.venv\Scripts\python.exe -m unittest discover -s tests -v
.venv\Scripts\ruff.exe check pyosik.py tools tests
```

`tests/test_pyosik.py` подменяет Android SDK на границе интеграции, сохраняя
настоящие `grpclib` и `protobuf`. Тесты проверяют запрос распознавания,
дедупликацию событий, выбор аккаунта, очередь, ограничения приватности,
отключение плагина, ошибки редактирования и сохранение длинного текста.

`tools/dev.py list` показывает состояние установленных плагинов.
`tools/dev.py disable` отключает Pyosik.
Журнал доступен командой:

```powershell
C:\adb\adb.exe logcat -s plugin.pyosik
```

Ключи и распознанный текст в журнал плагина не записываются.
Исходные настройки Windows, EXE, логи и временные материалы исключены из Git.

Схема protobuf встроена в `pyosik.py` как сжатый дескриптор, сгенерированный
из официальных файлов NVIDIA. Для воспроизводимого обновления:

```powershell
.venv\Scripts\python.exe tools/update_schema.py
```

Генератор закреплён на ревизии
`268890b7286031a6d4950e34f7ce13ed0d4ce621` репозитория `nvidia-riva/common`.
Для работы на Android не используются `grpcio`, нативные Python-расширения
или Windows-помощник. `grpcio-tools` нужен только на компьютере для генерации.

## Проверено

На Pixel 8 Pro с AyuGram и SDK 1.4.5.7 проверены установка, включение,
подписка на события отправки и реальный gRPC-запрос с телефона в NVIDIA.
Синтезированная фраза `This is a test of voice message transcription.`
распознана полностью. Сквозная проверка настоящего голосового в «Избранном»
подтвердила распознавание и успешное добавление подписи за 0,9 секунды.
